Download

Install it on your Mac.

Download the Apple silicon DMG, verify its published SHA-256 checksum, drag QuotaCreature into Applications, then launch it from Finder. The release is ad-hoc signed but not Apple-notarized, so the first launch may require Control-click → Open. Never disable Gatekeeper to launch it.

Opt-in

Claude Code

Claude has no endpoint for reading limits without a turn, so the Claude tab shows a one-line statusLine command to copy into your own Claude Code settings. Usage appears after one real conversation.

Local by design

No account, server, or history to maintain.

QuotaCreature has no direct network client, usage reporting, stored usage history, or credential-file reader. It starts the existing Codex CLI with a fixed App Server request over local standard input and output.

  • Fixed local Codex command
  • Filtered child-process environment
  • No copied prompt, transcript, or account identity
  • Optional reset reminder stays on the Mac

Questions

Small answers before you build.

Why does the app show unavailable?

Codex may be signed out, outdated, or not exposing limits. The app shows a generic unavailable state instead of parsing local files or terminal output. See the installation guide.

Does it upload my usage data?

No. The companion has no direct network client or usage reporting. Read the privacy notice for the exact local state.

Does it support Claude Code?

Yes, once you opt in by adding the statusLine command the Claude tab shows. QuotaCreature never invokes Claude, edits your Claude settings, or reads credentials, sessions, logs, or terminal output.

Why does macOS show a security warning?

The release is ad-hoc signed but not Apple-notarized. Verify the published checksum, then Control-click the app in Finder and choose Open. Do not disable Gatekeeper or clear quarantine. See the installation guide.
